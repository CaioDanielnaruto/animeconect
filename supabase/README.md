# Banco de dados do AnimeConect

1. Crie um projeto em https://supabase.com/dashboard.
2. Abra **SQL Editor**, cole o conteúdo de `schema.sql` e execute.
3. Em **Project Settings > API**, copie a URL do projeto e a chave pública `anon`.
4. Copie `.env.example` para `.env` e substitua os valores.

O arquivo `.env` é ignorado pelo Git e nunca deve ser publicado. A chave `service_role`
também nunca deve ser usada no navegador.
